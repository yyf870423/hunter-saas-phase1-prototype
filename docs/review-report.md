## 3. 权限与数据边界

1. 运营端仅展示工作空间账号元数据、脱敏任务状态、错误码、依赖和诊断包，不展示候选人、公司、岗位、附件、用户输入或 Agent 输出正文。
2. 用户端自动化可以按配置减少人工确认，但 Hunter 强制门禁不可关闭。
3. 推荐、面试安排、薪资、Offer 和录取等承诺动作保持人工处理。
4. 等待异步回复的业务进程不会显示为持续消耗额度的运行任务。

## 4. 视觉与交互结论

- 设计语言由 Token 和公共组件统一承载，业务页只负责布局和业务编排。
- 页面未使用可见的浏览器默认 `select`、`checkbox`、`radio`。
- 图标全部由本地 SVG 组件输出。
- 用户端和运营端在信息密度、导航和权限提示上保持清晰区分，同时复用相同基础组件。
- 工作台以业务主线为唯一首要入口，支线任务、信号与机会依次降低层级，行动队列默认折叠，不再同时展示多个同权列表。
- 桌面、iPad、iPhone 均保留完整操作入口，不存在已知页面级横向溢出。
