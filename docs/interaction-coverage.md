# Hunter SaaS 阶段一交互覆盖清单

## 1. 页面范围

原型共覆盖 **60 个页面**：45 个用户端页面、15 个运营端页面。完整编号和路由可在 `#/review` 查看，并可逐页打开。

| 页面组     | 编号         | 主要操作                                                             |
| ---------- | ------------ | -------------------------------------------------------------------- |
| 访问与框架 | U01–U06      | 登录、申请、开通、导航、通知、全局搜索、主题切换                     |
| 业务主线   | U07–U12      | 新建、查重、进入、暂停、恢复、补充输入、查看产物和支线               |
| 任务与信号 | U13–U16      | 搜索筛选、查看过程、暂停恢复、技术详情、处理信号、创建任务           |
| 业务资产   | U17–U34、U45 | 列表筛选、详情跳转、关联对象、匹配判断、沟通、推进、证据查看         |
| 数据进入   | U35–U37      | 选择类型、上传、格式校验、重复预检、确认、后台进度和失败反馈         |
| 账户与权益 | U38–U44      | 资料、通知、自动化授权、平台登录、订阅、用量、数据导出和诊断包       |
| 运营端     | O01–O15      | 申请审核、工作空间、订阅权益、用量、任务诊断、错误、依赖、公告和审计 |

## 2. 六条端到端用户故事

| 故事                 | 页面入口                          | 正常路径                                         | 异常与恢复路径                         | 覆盖状态 |
| -------------------- | --------------------------------- | ------------------------------------------------ | -------------------------------------- | -------- |
| 招聘信号形成岗位     | U04 → U15 → U16 → U09 → U23 → U25 | 查看信号、启动客户开发、确认机会、建立岗位       | 重复任务、证据不足、等待联系人回复     | 已覆盖   |
| 岗位招聘推进候选人   | U10 → U14 → U27 → U34 → U45       | 自动召回、审核匹配、联系、记录人工推进           | 平台失效、任务暂停、候选人拒绝         | 已覆盖   |
| 人才摸排形成关系资产 | U11 → U29 → U21/U27 → U14         | 建立公司、方向、角色、关键人物和关系证据         | 关系证据不足、创建补全支线             | 已覆盖   |
| 新资料回流并重新匹配 | U34 → U14 → U27 → U45             | 处理文字/链接/文件、查重、更新档案、局部重新匹配 | 不支持文件、重复候选人、解析失败       | 已覆盖   |
| 异步回复继续原任务   | U34 → U14                         | 等待回复不持续耗用，收到回复后继续               | 超时提醒、人工补录、平台登录恢复       | 已覆盖   |
| 故障与权益处理       | U13/U14 → U41/U43/U42             | 查看故障、处理登录、恢复检查点、查看用量         | 额度不足、订阅到期、依赖异常、权限受限 | 已覆盖   |

可在 `#/review/stories` 逐条体验，页面会显示对应入口和完成条件。

## 3. 公共交互覆盖

| 交互            | 正常路径                                 | 异常路径                           | 覆盖位置                   |
| --------------- | ---------------------------------------- | ---------------------------------- | -------------------------- |
| 搜索与筛选      | 输入、回车、单选、多选、多级、日期、清空 | 无结果、输入为空、筛选组合无数据   | 列表页、`#/components`     |
| 表格与分页      | 行打开、操作列、截断 Tooltip、分页       | 空表、权限受限、加载失败           | 资产列表、运营列表         |
| 新建与编辑      | 表单输入、保存、跨页更新                 | 必填缺失、重复命名、禁用提交       | 主线、账户、公告、联系人   |
| 删除与危险操作  | 二次确认、操作后 Toast、列表更新         | 前置条件不满足、按钮禁用           | 任务、公告、数据管理       |
| Modal 与 Drawer | 打开、确认、关闭、短视口滚动             | Loading、Error、Disabled、关闭保护 | 全局搜索、通知、审核、详情 |
| 上传与导入      | 选文件、预检、确认、后台处理             | 格式错误、重复数据、解析失败       | U35–U37                    |
| Agent 任务      | 查看步骤、暂停、恢复、技术详情           | 输出校验失败、平台失效、重试上限   | U13–U14                    |
| 自动化与授权    | 人工确认、自动确认设置、强制门禁         | 无权限、额度不足、订阅到期         | U40–U43                    |
| 运营审核        | 查看脱敏摘要、审批、记录审计             | 权限不足、诊断失败、不可见业务正文 | O03–O15                    |

## 4. 业务主线通用协议覆盖

| 业务主线   | 渐进过程                                                    | 结构化操作                                     | 自然语言操作                             | 等待与分支                           |
| ---------- | ----------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------- | ------------------------------------ |
| 客户开发   | 招聘信号 → 联系人 → 联系内容 → 外联 → 客户回复 → 招聘机会   | 联系人、联系草稿和客户机会逐项确认             | 可调整联系人优先级、联系边界和机会处理   | 等待客户回复；发现岗位招聘支线       |
| 岗位招聘   | 多渠道召回 → 去重补全 → 匹配 → 候选人审核 → 联系 → 信息回流 | 逐人决定、按建议处理、按分数处理、加入岗位储备 | 支持分数条件、明确排除和批量去向组合指令 | 等待候选人回复；地点变化后局部重匹配 |
| 人才摸排   | 公司与方向 → 组织 → 关键人 → 关系 → 覆盖缺口                | 关系逐项审核和支线处理                         | 支持按证据数量批量确认或保留待核验       | 发现新团队后建议客户开发支线         |
| 候选人求职 | 岗位召回 → 异步沟通 → 新简历 → 字段差异 → 局部重匹配        | 文件授权、字段更新和影响范围确认               | 支持资料处理边界和重匹配范围指令         | 等待候选人回复；新资料恢复任务       |

自然语言与结构化操作都转换为同一种业务命令。批量写入、外部联系和敏感资料读取必须先展示对象、范围、例外和执行边界；完成后的复杂结果仍可重新打开只读复核。

## 5. 组件状态覆盖

`#/components` 集中展示并可操作以下状态：`normal`、`hover`、`focus`、`loading`、`empty`、`error`、`disabled`、`permission-limited`、成功、风险、警告、暂停和恢复。业务页面同时提供真实上下文中的异常与恢复路径，不以纯样式占位替代。

## 6. 响应式覆盖

- 桌面宽屏：1440×900、1366×768。
- iPad：820×1180。
- iPhone：390×844。
- 移动端保留全部功能，表格按场景转换为可扫描信息列表或可控横向区域。
- 导航、Sticky、Drawer、Modal、分页、长文本、岗位推进和人才摸排均纳入横向溢出检查。
